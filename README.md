# QueuePro: Industrial Queueing Simulator Pro

QueuePro is a professional Discrete Event Simulation (DES) SAAS platform designed for Process Engineers, Data Scientists, and Educators. Optimize your service floor, eliminate bottlenecks, and validate system capacity using rigorous stochastic modeling.

## 🚀 Key SAAS Features

- **Dual-View Visualization:** Real-time 3D agent-based floor planning and interactive 2D pan/zoom layouts.
- **Jackson Network Builder:** Connect multiple service nodes with probabilistic routing and shared global resources.
- **Data Lab:** Fitting empirical data (CSV/Logs) to Erlang and Poisson distributions using automated statistical inference.
- **SAAS Capabilities:** Cloud-saved projects, multi-user collaboration, and Stripe-integrated premium tiers.

## 🧪 Industrial Applications

- **Healthcare:** Triage and outpatient flow optimization.
- **Retail:** Checkout capacity planning and queue management.
- **Telecom:** Server request handling and load balancing models.
- **Manufacturing:** WIP (Work in Progress) analysis and throughput stabilization.

## 🛠 Tech Stack (Production Ready)

- **UI:** React, Tailwind CSS, Three.js.
- **Core:** TypeScript Stochastic Simulation Engine.
- **Cloud:** Google Cloud (Run, SQL, Firebase), Stripe.

## 📊 Subscription Tiers

- **Free Tier:** Basic M/M/s modelling for students.
- **Premium Tier:** Professional network design and advanced data fitting for industrial process engineering.
